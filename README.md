# لندی | Landy

[![مشاهده نسخه آنلاین](https://img.shields.io/badge/مشاهده-نسخه%20آنلاین-0A66C2?style=for-the-badge)](https://mehrandevs.github.io/Landy/)
[![مخزن GitHub](https://img.shields.io/badge/GitHub-مخزن%20پروژه-181717?style=for-the-badge&logo=github)](https://github.com/mehrandevs/Landy)

**Landy** یک قالب وب‌سایت لندینگ‌پیج فارسی با محوریت معرفی اپلیکیشن است. این پروژه با HTML، CSS و JavaScript پیاده‌سازی شده و بخش‌هایی مانند معرفی محصول، ویژگی‌ها، تصاویر محیط برنامه، پلن‌های قیمت‌گذاری و راه‌های ارتباطی را در یک صفحه ارائه می‌کند.

> این پروژه یک رابط کاربری Front-end است و در ساختار فعلی آن بک‌اند یا سیستم مدیریت محتوا وجود ندارد.

## نسخه آنلاین

**[مشاهده وب‌سایت Landy](https://mehrandevs.github.io/Landy/)**

## امکانات

- طراحی راست‌چین و فارسی (RTL)
- صفحه اصلی معرفی اپلیکیشن با بخش‌های مجزا
- منوی ناوبری واکنش‌گرا
- هدر ثابت با تغییر ظاهر هنگام اسکرول
- معرفی ویژگی‌ها و قابلیت‌های محصول
- نمایش تصاویر و پیش‌نمایش محیط اپلیکیشن
- اسلایدر تصاویر با کنترل‌های قبلی و بعدی
- بخش معرفی پلن‌ها و قیمت‌گذاری
- بخش دانلود اپلیکیشن و راه‌های ارتباطی
- استفاده از فونت‌های فارسی و آیکون‌ها

## ساختار پروژه

```text
Landy/
├── fonts/                   # فونت‌های فارسی و آیکون
├── img/
│   ├── logo/                # لوگو
│   ├── mock-up/             # تصاویر پیش‌نمایش اپلیکیشن
│   ├── showcase/            # تصاویر ویترین
│   ├── store/               # تصاویر فروشگاه اپلیکیشن
│   └── testimonial/         # تصاویر نظرات کاربران
├── script/
│   └── js.js                # کدهای JavaScript
├── style/
│   ├── font-awesome.css
│   ├── font-awesome.min.css
│   ├── media-queries.css    # استایل واکنش‌گرا
│   └── style.css            # استایل اصلی
├── index.html               # صفحه اصلی
└── README.md
```

## بخش‌های وب‌سایت

| بخش | توضیحات |
| --- | --- |
| Header | لوگو و منوی ناوبری |
| Banner | معرفی اولیه اپلیکیشن |
| Features | ویژگی‌های اصلی محصول |
| About | معرفی اپلیکیشن |
| App Properties | قابلیت‌ها و مزیت‌ها |
| Installation | بخش معرفی نحوه نصب |

| Contact | بخش ارتباط با کاربران |

## تعاملات JavaScript

کدهای تعاملی پروژه در فایل `script/js.js` قرار دارند:

- باز و بسته شدن منوی موبایل
- تغییر ظاهر هدر هنگام اسکرول
- جابه‌جایی تصاویر اسلایدر بخش ویترین
